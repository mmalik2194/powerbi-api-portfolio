## Project 1
**Title:** Advanced Power BI Dashboard — World Bank API

**Role:** Power BI developer and data analyst

**Description:** Built a three-page Power BI report from the public World Bank API covering 217 economies. Designed a star schema and 30 DAX measures for weighted KPIs, dynamic metric selection, Top N ranking, regional benchmarks, CAGR and indexed trends. Implemented country drillthrough and coverage diagnostics. Verified measures in Power BI Desktop and reconciled key results independently. Personal portfolio project using public data.

**Skills:** Microsoft Power BI, DAX, Power Query, Data Modeling, API Integration.

**Demo sequence:** Executive KPIs → switch metric → change Top N → right-click country → drillthrough → explain peer gap → inspect data quality.

## Project 2
**Title:** Power BI Solar Analytics — NASA API & What-If Modeling

**Role:** Power BI developer and analytics modeler

**Description:** Created a three-page Power BI solar/weather planning report using NASA POWER API data for five Australian cities. Built 26 DAX measures with capacity and performance-ratio controls, rolling 30-day energy, YoY/YTD comparisons and monthly anomalies. Added completeness and duplicate-key checks. Validated scenario scaling and date calculations in the native engine. Personal demonstration; energy results are modeled scenarios, not metered generation.

**Skills:** Microsoft Power BI, DAX, Power Query, Data Visualization, Data Analysis.

**Demo sequence:** Compare cities → choose one year → inspect rolling trend → change capacity 100 to 250 kWp → show 2.5× energy → adjust rain threshold → inspect quality controls.

**Suggested images:** solar_executive.png, solar_quality.png.
